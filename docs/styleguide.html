颜色Color

11 个语义角色，两套取值。组件只引用角色名，不写具体色值。

卡片上方色块按当前主题渲染；val 为 CSS 变量所需的 R G B 三元组，因此可直接使用 bg-brand/10 这类透明度修饰符。

字体与字号Typography

0.5px 步进的密集阶梯，按语义取值，不随手写。

中英混排时拉丁字体优先、中文回退到苹方/微软雅黑；数字与代码统一用等宽字体。

间距、圆角与阴影Space · Radius · Elevation

4px 基准；控件 14px、容器 18px、胶囊 full；阴影只表示「浮起」。

按钮Buttons

四种语义、一种形状。主按钮一屏只有一个。

共同基类：rounded-xl · px-3.5 py-2 · text-sm · font-medium · active:scale-[.98]。禁用态是 50% 透明 + 屏蔽点击，不是变灰。

布局与断点Layout

只有两个断点：640 与 1024。中间态没有真实场景，多一个断点就多一套要维护的布局。

< 640 单列
≥ 640 内边距 24px
≥ 1024 侧栏 252px

动效Motion

只解释状态变化，不做表演；位移不超过 6px。

fade-up · .28s · cubic-bezier(.2,.8,.2,1) · 6px
弹窗、Toast、首屏列表都使用这一条曲线；按下反馈统一为 scale(.98)，hover 只改颜色不改尺寸。
